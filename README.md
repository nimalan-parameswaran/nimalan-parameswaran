# ✦ SPACE//SHOOTER

> One pilot. Infinite space. How long can you survive?

A neon arcade space shooter built with vanilla HTML, CSS and JavaScript. No frameworks, build tools, or server required.

## ▶ Play the game

**[Launch Space Shooter](https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/)**

Replace the URL above after enabling GitHub Pages for this repository.

## 🎮 Controls

- **Move:** `←` / `→` or `A` / `D`
- **Fire:** `SPACE`
- **Pause / resume:** `P`
- **Touch devices:** drag your ship and tap **FIRE**

Destroy incoming enemies, avoid collisions, and earn 100 points per enemy. Your best score is saved in your browser.

## 🚀 Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser. For the profile README link, use the GitHub Pages URL instead.
3. Press **START MISSION**.

## 🌌 Features

- Responsive canvas gameplay
- Keyboard and touch controls
- Particle bursts, neon effects, and animated starfield
- Score, lives, increasing difficulty, and local best score
- Plain HTML/CSS/JavaScript; no dependencies
